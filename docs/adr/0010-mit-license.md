# 0010. MIT license for code and content

- **Status:** Accepted
- **Date:** 2026-10-12

## Context

The repository is public and invites contributions. Until a license exists, default copyright applies and nobody may legally reuse or contribute to the work. Educational projects often split licenses (for example MIT for code and CC BY 4.0 for prose), which requires contributors and reusers to track which license covers which file.

## Decision

Everything in the repository — code, lessons, diagrams and generated assets — is licensed under the [MIT License](../../LICENSE).

## Consequences

- One permissive license, simple for contributors and reusers: keep the copyright and license notice, otherwise reuse freely.
- MIT is written for software; it is permissive enough for prose and diagrams, but reusers are not required to credit lessons beyond keeping the notice.
- Third-party material must only be added if its license is compatible and its attribution requirements are met.
