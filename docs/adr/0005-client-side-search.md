# 0005. Client-side search over a build-time index

- **Status:** Accepted — implementation in Phase 4
- **Date:** 2026-10-12

## Context

Search must work on a static site, without third-party services or tracking, and be testable.

## Options considered

1. **MiniSearch over a JSON index generated by `scripts/content.ts`** — small, mature, works identically in `next dev` and production, unit-testable.
2. **Pagefind** — indexes built HTML and chunks large indexes well, but needs a production build before search works in development.
3. **Algolia or another hosted search** — excellent relevance, but external, account-bound and a privacy consideration.

## Decision

MiniSearch, with the index built from the plain text that `lib/content/mdx-text.ts` already extracts, loaded on first use of search.

## Consequences

Revisit Pagefind if the index grows past a comfortable size (roughly a few hundred lessons).
